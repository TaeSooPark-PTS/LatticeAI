# Lattice AI 10.0.0 — Plain Language

> **Status: historical** — point-in-time release note.

릴리스일: 2026-07-28

## 한 줄 요약

만든 사람이 아니라 **처음 보는 사람이 읽을 수 있는 제품**으로 바꿨습니다.
실제 로컬 모델(Gemma 4 26B · MLX)을 올린 상태로 모든 화면을 열고 모든 버튼을
눌러, 깨진 것과 개발자 용어를 찾아 고쳤습니다. 상단바에 한국어/English 전환을
넣고 양쪽 언어를 완전히 맞췄습니다.

## 첫 화면 — 11개 블록에서 4개 구역으로

```
            🧠  ← 누르면 기억 지도
   말하고, 넣으면, Brain이 연결합니다.
   기억 12개, 주제 291개를 기억하고 있어요.

 ┌──────────────────────────────────────────┐
 │ 질문하거나, 자료를 붙여 넣거나…            │
 │ [문서][이미지][파일][폴더][노트][웹]  [보내기] │
 │ ────────────────────────────────────────  │
 │ 에이전트 자율성  ●엄격  ●신뢰  ●바이패스     │
 └──────────────────────────────────────────┘
      [초점 정리]  [연결 탐색]  [후속 작업]
      🕘 지난 대화 · ✨ Brain이 정리한 내용
```

- **자료 넣기가 대화창 안으로.** 파일·폴더·노트·웹이 문서·이미지 옆에 들어가고
  별도의 "Brain에게 가르치기" 패널은 사라졌습니다. 대화 중에도 같은 버튼을
  씁니다.
- **홈에는 그래프가 없습니다.** 카드 8개·연결선·흐름 다이어그램을 전부 뺐고,
  지식 그래프는 **Brain 그림을 눌렀을 때만** 열립니다.
- **자율성과 화면 설정이 손에 닿는 곳으로.** 자율성은 대화창 하단에, 화면
  모양은 상단바에. 환경설정까지 들어갈 필요가 없습니다.
- 30초 체험·첫 5분 온보딩 카드는 제거했습니다.

**빠진 기능은 없습니다.** 자동화 제안·오늘의 브리핑·수집 상태·지식 정원·근거
검토는 "Brain이 정리한 내용" 안으로 옮겨 한 번의 클릭으로 닿습니다.

## 한국어와 영어, 전 화면

상단바에 `한국어 / English` 전환이 생겼고, 어느 화면에서나 바꿀 수 있습니다.

백엔드는 하나의 어휘를 유지하고 화면만 사용자의 언어로 읽히도록, **안정적인
id를 기준으로** 번역합니다:

| 대상 | 키 | 전 → 후 (ko) |
| --- | --- | --- |
| 기억 계층 | `brain.memoryTier.*` | `Workspace Memory` → 작업공간 기억 |
| 에이전트 역할 | `act.agentRole.*` | `Researcher` → 조사 담당 |
| 자동화 레시피 | `act.recipe.*` | `Daily Memory Digest` → 오늘의 기억 정리 |
| 노드/상태 배지 | `ui.entity.*` | `Task` → 할 일, `Indexed` → 정리 완료 |
| 페이로드 필드 | `ui.field.*` | `Current Model` → 지금 쓰는 모델 |

점검 방법: 각 언어에서 8개 화면의 모든 표시 텍스트를 수집해, en일 때 한글이
남았는지 / ko일 때 영어가 남았는지 확인했습니다. 남은 것은 사용자 데이터와
고유명사(모델 이름, 파일명, 대화 내용)뿐입니다.

## 숫자가 무엇을 셌는지 말합니다

```
전: 출처 반영률  12%
후: 출처가 남은 기억  35 / 291개
    기억 291개 중 35개는 어디서 왔는지 기록돼 있어요.
    대화하며 생긴 기억에는 출처가 없을 수 있습니다.
```

모델 이름도 같습니다 — `mlx-community/gemma-4-26b-a4b-it-4bit` 대신
`Gemma 4 26B A4B Instruct`.

## 써 보고 나서야 나온 결함들

측정으로 확인하고 고친 것만 적습니다.

**폴더 버튼이 브라우저에서 아무 일도 안 했습니다.** `pickFolder()`가
데스크톱 전용 `selectFolder()`만 호출해 언제나 `null`을 받았습니다. Capture
화면에는 이미 브라우저 경로가 있었지만 Brain 홈에는 없었습니다.
`frontend/src/lib/folderPicker.ts`가 데스크톱 / File System Access /
`<input webkitdirectory>` 세 경로를 한 곳에서 결정합니다.

**대화 화면 브레인 그림이 311px.** `size="trace"`는 작은 표식용인데 크기
규칙이 없어 기본값 `clamp(220px, 28vw, 320px)`를 상속했습니다. 헤더가
sticky라 화면의 46%를 영구히 차지했습니다.

**답변 끝이 입력창 뒤에 숨었습니다.** 스트림에 하단 여백이 없었고, 제안
패널·저장 알림·세부 정보가 입력창 **뒤에** 렌더링돼 입력창이 화면 중간에 떠
있었습니다. 이제 입력창 뒤에는 아무것도 오지 않습니다.

**패널이 값 대신 필드 이름을 출력했습니다.**
`Runtime → Ready, Version, Execution Mode, Mode +4` — 중첩 객체를 키 목록으로
그리고 있었습니다. 이제 의미 있는 값을 고르고, 없으면 "내용 N가지"라고 셉니다.

**설명문이 잘려 읽을 수 없었습니다.** 버튼 라벨용 `white-space: nowrap`이
버튼 안 설명까지 상속돼 347px 문장을 288px에 밀어 넣었습니다.

**모델이 쓴 마크다운이 그대로 보였습니다.** 검색 결과와 그래프 노드에
`**요약하자면,**`이 그대로 나왔습니다. `plainText`가 제거합니다.

**쓸 수 있는 모델이 비활성 버튼 5개 뒤에 묻혔습니다.** 목록을 사용 가능한
순서(불러옴 → 준비됨 → 받아둠 → 나머지)로 정렬했습니다.

## 그 밖에

- 설정의 "화면 모양"에 섞여 있던 기본/고급/관리자를 "보여줄 내용의 양"으로
  분리했습니다. 색 설정이 아니라 정보량 설정입니다.
- 같은 화면에 탭 "찾기"와 버튼 "찾기"가 있어 헷갈렸습니다. 버튼을
  "기억에서 찾기"로 바꿨습니다.
- 임베딩 상태를 고급 모드에서도 평문으로 먼저 보여줍니다
  (`Grade: fallback` → "기본 검색 사용 중 (의미 모델 없음)").
- 검색 결과가 제목과 요약에 같은 문장을 두 번 찍던 것을 고쳤습니다.

## 알려진 한계

- 백엔드가 생성하는 일부 안내 문장(예: Postgres DSN 안내)은 서버 쪽에서 영어로
  만들어져 그대로 표시됩니다. 서버 i18n은 이번 범위에 넣지 않았습니다.
- 사용자가 넣은 자료와 대화 내용은 번역하지 않습니다. 원문 그대로가 맞습니다.
