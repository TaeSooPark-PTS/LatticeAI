# Lattice AI 10.5.0 — Everyday Words

> **Status: historical** — point-in-time release note.

릴리스일: 2026-08-03

## 한 줄 요약

**10.4.0이 코드가 딛고 선 땅에 이름을 붙였다면, 10.5.0은 읽는 사람이 딛고 선 땅에
이름을 붙입니다.** 처음 켠 사람이 만나는 모든 화면이 그 사람이 쓸 법한 말로
설명하고, 엔진의 어휘는 그것을 원한 사람이 있는 고급 모드 뒤로 갑니다. 기능은
하나도 지우지 않았습니다.

---

## 1. 자율성 다이얼은 이제 모드 이름이 아니라 문장입니다

| 이전 | 이후 |
| --- | --- |
| 엄격 | 먼저 물어보기 |
| 신뢰 | 웬만하면 알아서 |
| 바이패스 | 거의 다 알아서 |

이름만 바꾼 것이 아니라, 각 설정이 **무엇을 묻지 않고 하는지** 한 줄로 말합니다.

> 먼저 물어보기 — 읽는 일은 알아서 하고, 무언가를 쓰거나 실행하기 전에는 나에게
> 확인받습니다.
>
> 거의 다 알아서 — 작업 공간 안에서는 거의 묻지 않고 진행합니다. 그래도 위험한
> 작업은 계속 막혀 있어요.

경고 문구도 모드 이름을 부르는 대신 **무엇이 여전히 막혀 있는지**를 말합니다:
"이 설정에서는 평소의 확인 창이 뜨지 않습니다. 시스템 폴더를 지우는 것처럼
되돌릴 수 없는 작업은 그래도 막혀 있어요."

### 같은 설정이 두 이름으로 불리지 않게

홈 화면의 다이얼(`BrainQuickControls`)과 설정 패널(`PermissionModePanel`)이
각자 서버 카탈로그를 번역하고 있었습니다. 이제 둘 다
`frontend/src/lib/permissionCopy.ts` 한 곳을 읽습니다.

조회는 **모드 id 기준**이고, 모르는 id는 서버가 준 현지화 라벨로 떨어집니다.
서버가 나중에 모드를 하나 더 추가해도 화면에 그대로 나온다는 뜻이고, 그
폴백에는 전용 테스트가 붙어 있습니다 — 번역 표는 방치하면 **의도치 않은
허용목록**이 되기 때문입니다.

## 2. 자료가 기억이 되기까지, 세 단계

'진행 상황'(구 '흐름') 탭은 기본 모드에서 **아예 숨겨져 있었고**, 열어 봐도 원시
API 응답 패널 두 개가 전부였습니다. 이제 세 단계를 이름과 함께 보여줍니다.

1. **내용 읽기** — 문서와 웹페이지에서 글과 표를 그대로 읽어옵니다.
2. **뜻 파악하기** — 무슨 내용인지 파악해 두어서, 똑같은 단어로 묻지 않아도
   찾아낼 수 있게 합니다.
3. **기억에 연결하기** — 이미 아는 내용과 이어 붙여, 관련된 자료가 함께 떠오르게
   합니다.

`<ol aria-label="자료가 기억이 되는 3단계">`로 렌더링되고, 단계마다 정리를
기다리는 중 / 진행 중 / 끝남 상태가 붙습니다. 장식용 아이콘은
`aria-hidden="true"`입니다. 원시 패널 두 개는 고급 모드에 그대로 남아 있습니다.

수집 단계 이름도 기계의 일이 아니라 **내 파일에 일어나는 일**로 바뀌었습니다:
준비 → 파일 여는 중, 파싱 → 내용 읽는 중, 임베딩 → 뜻 파악하는 중, 인덱싱 →
기억에 연결하는 중, 메모리화 완료 → 기억 완료. 임베딩 모델 교체 안내도
"찾는 방식이 바뀌었어요 / 기억 다시 정리하기"가 되었습니다.

## 3. 실행 기록은 내가 붙인 이름으로

이전에는 실행 목록이 `wf-run-approval` 같은 데이터베이스 id와
`awaiting_approval` 같은 원시 토큰을 그대로 보여줬습니다.

- 제목은 워크플로 이름 → 목표 → title/query 순으로 고르고, 아무것도 없으면 기본
  모드에서 "3번째 작업"으로 셉니다. id는 **고급 모드에서만** 이름 아래 작은
  글씨로 남습니다.
- 상태는 토큰별로 번역합니다. `awaiting_approval` → "내 승인 기다리는 중",
  `retried_ok` → "다시 시도해서 완료". 매핑에 없는 토큰은 자기 자신을 찍는 대신
  "알 수 없음"이 됩니다.
- 기본 모드에 **"자동으로 실행되는 작업"** 요약이 생겼습니다. 워크플로 이름과
  "새 자료가 들어오면 / 정해진 시간에 / 내가 눌렀을 때만 / 조건이 맞으면", 그리고
  "켜져 있어요 / 지금은 멈춰 있어요". 노드 캔버스와 JSON 붙여넣기 상자는 만드는
  사람의 도구라서 고급 모드에 그대로 있습니다.

## 4. 작은 정직성 수정 두 가지

**반쯤 번역된 문장.** 모델 레지스트리가 영어로만 주는 설명을 단어 단위로
치환하다 보니 "uses the 이 로컬 모델 형식 로컬 모델 지원 format" 같은 문장이
화면에 나왔습니다. 이제 한글이 없고 여섯 단어 이상인 문장은 통째로 한국어 설명
("이 모델은 지금 이 컴퓨터에서 실행할 수 없어요. 아래 호환 대안 중에서 골라
보세요.")으로 대체됩니다.

**Brain 상태 패널.** `schema_version`과 스토리지 엔진 이름 대신, 사람이 실제로
궁금해하는 것에 답합니다 — "저장 위치 / 내 컴퓨터", "가져가기 / 언제든 내보낼 수
있어요". 원래 값은 고급 모드에 남아 있습니다.

## 5. 공개되던 스크린샷 자체가 틀려 있었습니다

`scripts/capture_release_evidence.mjs`는 캡처 전에
`localStorage.setItem("lattice.mode", "advanced")`를 넣고 있었습니다. 앱의 실제
기본값은 `basic`입니다. 즉 **README에 실리던 모든 프레임이, 처음 쓰는 사람은
평생 보지 못할 원시 페이로드 패널과 스토리지 엔진과 훅 로그를 보여주고
있었습니다.**

이제 기본값 그대로 캡처합니다. 그 결과 프레임 두 개가 바뀌었습니다.

- `09-model-setup-status.png` — 기본 모드에서는 knowledge-flow 띠가 펼쳐지지
  않아 04(Brain 홈)와 사실상 같은 그림이 되었습니다. `09-automation-runs.png`
  (이름 붙은 실행 기록과 말로 된 상태)로 교체했습니다.
- `11-knowledge-journey.png` — 세 단계 여정을 새로 싣습니다.

워크스루 GIF도 ffmpeg 기본 팔레트로 인코딩되고 있었습니다. 앱의 아이보리 배경이
**노랗게 디더링되고 초록이 올리브색으로** 나왔습니다 — README 맨 위 이미지가
존재하지 않는 제품을 보여주고 있었던 셈입니다. 이제 클립 자체에서 뽑은 팔레트로
인코딩합니다(1.5MB → 2.8MB, 실제 색).

## 6. 리뷰가 아니라 스윕이 지킵니다

`tests/visual/v3.spec.js`가 기본 모드로 10개 경로(`#/capture`, `#/models`,
`#/settings`, `#/hybrid-search`, `#/knowledge-graph`, `#/review`, `#/agents`,
`#/pipeline`, `#/runs`, `#/memory`)를 돌면서 두 가지를 확인합니다.

1. 화면이 실제로 그려지는가 (빈 프레임·서비스 불가 배너가 아닌가)
2. 엔진의 어휘(파싱, 임베딩, 인덱싱, 벡터, 스키마, `awaiting_approval`,
   `retried_ok`, `schema_version`, `sqlite` …)가 안 보이는가

이 목록은 장식이 아닙니다 — 이번 작업 **이전에는 `#/runs`가 바로 이 검사에
걸렸습니다.**

## 정직한 자기 평가

- **엔진 어휘 검사는 단어 목록입니다.** 전문 용어가 하나도 없으면서 여전히 무슨
  말인지 모를 문장은 잡지 못합니다.
- **남은 구멍 하나를 공개합니다.** 작업 → 실행의 승인 카드는 아직 원시 payload
  키를 그대로 라벨로 씁니다 — `Action`, `Action Label`, `User Email`.
  `09-automation-runs.png`에 그대로 찍혀 있고, 잘라내지 않았습니다. 다음 차례
  1순위입니다.
- **백엔드는 이번 릴리스에서 바뀌지 않았습니다.** 경로·요청·응답 스키마 변화
  없음. `frontend/openapi.json`은 `info.version`만 다릅니다.
- **프론트 커버리지는 32.9%입니다.** 10.4.0의 32.3%에서 소폭 올랐고, 70% 목표와는
  여전히 멉니다. 이번에 늘어난 테스트는 전부 이번에 바꾼 문구·폴백·오역 경로에
  붙었습니다.
