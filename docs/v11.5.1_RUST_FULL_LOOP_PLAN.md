## Y1 — 워커 AI-Worker 시임 3종 (Python, additive)

정찰 확정: 베어 LLM 완성 엔드포인트 없음, HTTP 제안 생성 불가,
`/tools/*`는 direct-surface 게이트(enforce_policy)라 루프용으로 부적합.

- `POST /agent/llm` — `LLMRouter.generate_as` 얇은 래퍼
  `{model_id?, message, context?, max_tokens?, temperature?}` → `{text}`.
  히스토리/영속 부작용 0. require_user + 레이트리밋.
- `POST /agent/tool` — 루프 전용 거버넌스 시임:
  `{tool, args, user_email?, workspace_id?}` →
  `check_role` + `dispatch_tool(HOOKS, source="agent")` 결과
  `{result}|{error}`. **서버측 모드 불변 가드는 유지**(우회 불가):
  `is_circuit_breaker`/destructive policy → 403,
  `classify_tool_call.fail_closed` → 409. 게이트 뒤:
  `LATTICEAI_AGENT_TOOL_SEAM=1`(기본 꺼짐 — 호스트가 자기 워커에만
  주입) 아니면 404. mode 게이팅 자체는 Rust 커널이 소유(사전 preflight).
- `POST /agent/change-proposal` — `ChangeProposalService.review(...)`
  verbatim 노출(제안-우선 경로). 같은 시임 게이트.

전부 100% 문·분기, ko/en 로컬라이즈, OpenAPI 재생성.

## Y2 — lattice-agent: 루프 오케스트레이터 (정찰 §1 명세 1:1)

- 결정적 헬퍼 포트+골든: `extract_action_details`(관용 체인 6단),
  `normalize_plan`(7규칙 순서), `infer_project_manifest`/`infer_file_target`,
  `artifact_checklist`, `requirement_coverage`, `_truncate_strings`,
  `filter_learnings`, PhaseBudgets/TranscriptBudget 기본값, 검증 매핑
  표(UNAVAILABLE/PASS-무증거/PASS-미충족/ROLLBACK/재시도/모순 verdict),
  실행 루프 규칙(budget, parse_failure_budget/escalate, `final`,
  `_is_repeated_create`, SCOPED 강제 주입, step_index 산식).
- 상태기계: run_to_completion 전이표 + 200캡(state_history 길이 기준),
  rollback 3-tier(git→snapshot→none, 종단 항상 FAILED) — snapshot/
  restore는 Rust 네이티브(sandbox Workspace 재사용).
- 승인 스토어: run_id/token 생성(urlsafe 16/32), sha256 토큰 해시,
  TTL 600s, 만료 후 86400s 보존→410+replan, 원자적 JSON 저장,
  `serialize/restore_run_context` 필드 계약 그대로(미지 상태→
  WAITING_APPROVAL).
- 워커 클라이언트: `/agent/llm`(plan/execute/verify/memory),
  `/agent/tool`(비-네이티브 도구), `/agent/change-proposal`(strict
  제안), 네이티브 실행은 X4 커널의 읽기 전용 세트.
- 라우트: `POST /rust/agent/run`(SSE `agent_step` 이벤트 + 최종 페이로드
  — Python `/agent` 프로토콜 동형), `POST /rust/agent/resume`,
  `GET /rust/agent/approvals`. lattice-host: worker_env에
  `LATTICEAI_AGENT_TOOL_SEAM=1` 주입 + mounts 시그니처 갱신.
- 골든: Python 생성기가 결정적 헬퍼 그리드 + fake-LLM 대본 기반
  end-to-end 상태 궤적(plan→…→terminal, 모드 3종 × 시나리오:
  정상 DONE/파스 예산 소진/반복 생성 가드/승인 대기·재개/만료 410/
  검증 재시도→FAILED/ROLLBACK)을 JSON으로 커밋, 양방향 계약.
  LLM 호출은 대본 주입(결정적) — Python 쪽도 같은 대본으로 구동.

## Y3 — 문서 생성 컨텍스트(B) 네이티브 (lattice-retrieval)

정찰 §4 명세 1:1: `search_for_document_generation`(2-lane LIKE 후보,
0.5/0.3/0.2 가중 + 1.2 타입 부스트, log1p(edge)/4, half-life 14d,
비안정 정렬의 삽입순 타이브레이크 재현), `multi_hop_context`(hop 라벨

for_generation` 전체 계약(self-model 블록 예산 산식 — 결합 개행 과금
포함, 섹션 4종 고정, `relevance: {:.2f}` 마크다운, `\n### ` 백오프 트림,
sources dedup 체인, trace). `summary_for_prompt`는 스토어 읽기 포트.
게이트웨이 `POST /rust/context/document`. 골든: 픽스처에 docgen 타입
노드 추가(스토어 재생성 — 기존 골든 재검증 필수), 신규 스위트 +
계약 pytest 확장.
