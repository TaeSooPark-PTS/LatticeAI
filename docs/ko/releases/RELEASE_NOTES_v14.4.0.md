# Lattice AI v14.4.0 — Measured Retrieval

출시일: **2026-11-27**

`v14.4.0`은 실제 EmbeddingGemma 2 및 `BAAI/bge-reranker-v2-m3` 가중치로 검색을 측정한 첫 릴리스입니다. 측정 과정에서 기존 해시 전용 게이트가 보지 못한 여러 결함이 드러났으며, 이번 릴리스에서 함께 고칩니다. v14.3.0에서 보류되었던 3D 뷰 항목 두 가지도 포함합니다.

## 주요 내용

### 1. 검색 수정

- **"최신" 질문에서 답변이 사라지지 않음:** 채팅이 최신성 정렬에 20개 후보 재랭크 풀을 넘기고 답변 크기인 5개 문서가 아니었기 때문에, 주제와 무관한 최신 문서가 정답을 밀어낼 수 있었습니다. 이제 최신성은 답변만 재정렬합니다.
- **top-k 절단 전에 워크스페이스 범위 적용:** worker가 없는 채팅 벡터 경로, 하이브리드 검색, 메모리 회상, 근사(HNSW) 인덱스가 전체 브레인을 먼저 순위 매긴 뒤 워크스페이스로 거르고 있어서, 범위 안의 결과가 모두 사라질 수 있었습니다.
- **`LATTICEAI_RERANK_CANDIDATES`를 20 초과로 설정해도 동작** (최대 64).
- **워커 시작 시 재랭커를 백그라운드 스레드에서 미리 적재:** 첫 질의들이 2초 재랭크 제한 시간을 넘겨 조용히 융합 순서를 유지하던 문제를 막습니다. 캐시된 재랭커는 시작 시 메모리에 적재되며, `LATTICEAI_RERANKER=off`로 끌 수 있습니다.
- **동시 콜드 요청에서 임베딩 모델을 한 번만 적재** (Hugging Face 및 MLX 제공자).

### 2. EmbeddingGemma 2 설정

- `pip install "ltcai[rag]"`가 이제 `torchvision`을 함께 설치합니다. EmbeddingGemma 2 프로세서는 텍스트만 처리할 때도 이를 import하므로, 없으면 모델을 적재할 수 없었고 보고되는 사유도 비어 있었습니다.

### 3. 평가의 정직성

- **v14.3.0 해시 게이트는 벡터 경로가 비활성인 상태로 측정되었습니다.** 평가가 8바이트 값을 4바이트 값으로 읽히도록 시드하여 모든 벡터 행이 제외되었습니다. 시드를 고쳤고, 하한선을 다시 측정해 올렸으며, 이제 벡터 경로가 아무것도 반환하지 않으면 게이트가 실패합니다.
- 채팅 경로 평가가 제품의 질의 계획, 임베딩된 질의 텍스트, 근거 게이트, 재랭크 후보 규칙, 구절 텍스트를 사용합니다.
- 야간 워크플로가 별도의 어휘 기준선 대신 제품 검색기를 측정합니다.
- 새 `scripts/run_neural_retrieval_eval.py`가 캐시된 실제 가중치를 오프라인으로 평가합니다.

### 4. 3D 살아있는 브레인

- 3D 뷰의 노드 라벨이 라벨 모드를 따르며, 한글 등 넓은 글리프를 고려한 겹침 제거를 적용합니다.
- WebGL 컨텍스트가 손실되면 렌더링을 일시 중지하고 상태를 알리며, 복구되면 재개합니다.
- 호버 피킹은 프레임당 최대 한 번 실행됩니다.

## 실제 모델 검색 평가

`datasets/rag_eval_v1.json` (`rag-eval-v1.0.0`, 문서 40개, 질의 320개, 응답 가능 248개), Apple Silicon (MPS), `sentence-transformers` 6.3.0, `transformers` 5.24.1, `torch` 2.15.0.

| 모드 | 검색기 | Recall@5 | MRR | nDCG@10 |
| --- | --- | :---: | :---: | :---: |
| 상수 타임스탬프 | 해시 임베더 | 0.9839 | 0.9026 | 0.9009 |
| 상수 타임스탬프 | EmbeddingGemma 2 | 1.0000 | 0.8770 | 0.8924 |
| 상수 타임스탬프 | EmbeddingGemma 2 + 재랭커 | 1.0000 | 0.9859 | 0.9806 |
| `valid_from` 타임스탬프 | 해시 임베더 | 0.9859 | 0.8858 | 0.8887 |
| `valid_from` 타임스탬프 | EmbeddingGemma 2 | 1.0000 | 0.8575 | 0.8785 |
| `valid_from` 타임스탬프 | EmbeddingGemma 2 + 재랭커 | 1.0000 | 0.9671 | 0.9666 |

여섯 번의 실행 모두에서 워크스페이스 경계 누출은 0이었고, 구버전 제외율은 1.0이었습니다.

같은 기기에서의 지연 시간: 질의 임베딩 p95 20 ms (이전 실행에서는 312 ms), 19개 후보 재랭크 p50 313 ms 및 p95 349 ms, 첫 재랭크 호출 1.6–1.9 s.

## 알려진 한계

- 데이터셋은 작고 합성 데이터입니다. 이 수치는 검색기 구성끼리의 비교이며, 개인 브레인에서의 품질을 예측하지 않습니다.
- 재랭커가 없으면 EmbeddingGemma 2는 이 데이터셋에서 해시 임베더보다 첫 정답 문서를 평균적으로 낮게 순위 매깁니다(MRR). 다만 5위 이내에서는 모두 찾아냅니다.
- "최신" 질문에서는 같은 주제의 더 새로운 문서가 답을 담은 문서 위에 놓일 수 있습니다. 여기에는 검증되지 않은 초안도 포함됩니다. 날짜 정렬은 출처를 알지 못합니다.
- 실제 모델 평가는 캐시된 가중치로 수동 실행됩니다. CI 게이트는 여전히 결정론적 해시 기반입니다.
- 워크스페이스 안의 문서는 사용자별로 비공개가 아닙니다.
