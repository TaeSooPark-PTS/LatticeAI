# 기능 요청 템플릿 (Feature Request)

> 이 문서는 [`.github/ISSUE_TEMPLATE/feature_request.md`](../../../.github/ISSUE_TEMPLATE/feature_request.md)의 한국어 안내 미러입니다.

```yaml
name: Feature request
about: 개선 사항이나 새로운 기능을 제안합니다
title: "[feature] "
labels: enhancement
assignees: ""
```

## 문제 정의 (Problem)

현재 어떤 워크플로가 어렵거나, 느리거나, 빠져 있나요?

## 제안하는 해결책 (Proposed solution)

원하는 동작을 구체적으로 설명해 주세요.

## 검토한 대안 (Alternatives considered)

검토해 본 다른 접근 방식이 있다면 설명해 주세요.

## 추가 맥락 (Additional context)

도움이 될 만한 스크린샷, 참고 자료 또는 예시 UX가 있다면 첨부해 주세요.
