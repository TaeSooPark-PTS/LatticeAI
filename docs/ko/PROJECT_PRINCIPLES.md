# 프로젝트 원칙 — 디지털 브레인 헌장 (Project Principles)

Lattice AI는 로컬 우선(local-first) **디지털 브레인 플랫폼(Digital Brain Platform)**입니다. 모델은 일시적이지만 지식은 영속적입니다. 사용자는 자신의 머신에서 지식, 기억, 맥락, 경험을 온전히 소유하며, 언제든 내보낼 수 있고 모든 사실이 어디에서 왔는지 끝까지 설명받을 수 있어야 합니다.

## 주권 (Sovereignty)

- 기본적으로 로컬 우선이며, 프라이버시 우선입니다.
- 사용자의 브레인(그래프, 기억, 대화, 노트, 출처 이력)은 사용자가 직접 통제하는 로컬 스토리지에 저장되며 언제든 백업하고, 내보내고, 다른 곳으로 옮길 수 있습니다.
- 어떤 데이터도 암묵적으로 머신 밖으로 나가지 않습니다. 배포된 페이지에서의 외부 CDN 호출, 클라우드 랑데부, 텔레메트리가 없습니다. 기기 간 지식 교환은 명시적이며 페어링과 서명을 거칩니다.
- 모델은 교체 가능한 구현체입니다. 에이전트, 검색(retrieval), UI 역시 마찬가지입니다. 진정한 자산은 브레인입니다.

## 하나의 브레인, 사일로 없음 (One brain, no silos)

- 모든 데이터 소스는 단일 수집 파이프라인을 통해 들어와 출처 정보(provenance)와 함께 Knowledge Graph에 안착합니다. 어떤 소스도 이를 우회하거나 별도의 병렬 저장소를 만들지 않습니다.
- 기억(Memory)은 브레인의 일부입니다. 일화 기억(대화), 의미 기억(선호도, 의사결정), 경험 기록은 모두 동일한 기반 저장소와 내보내기 포맷을 공유합니다.

## 정직성 (Honesty)

- **기능을 절대 꾸며내지 않습니다.** 완료할 수 없는 기능은 조작된 성공, 점수, 기록 대신 명시적인 상태(`simulation`, `awaiting_approval`, `unavailable`, 사유가 포함된 `skipped`)를 표면화합니다.
- 시뮬레이션 실행은 영속화된 레코드에 명확히 라벨링되며, 실제 경험으로서 브레인에 편입되지 않습니다.
- [`FEATURE_STATUS.md`](./FEATURE_STATUS.md)는 공개된 정직성 원장입니다. 모든 주장은 실제 코드로 추적되며, 미비점은 감추지 않고 명시적으로 기록합니다.

## 사용자 주체성 (User Agency)

- 사용자에게 선택을 요청하기 전에 명확히 설명합니다.
- 보호라는 명목으로 기능을 숨기지 않습니다.
- 출처, 위험, 한계에 대한 세부 정보를 숨기지 않습니다.
- 안전한 경로를 명확히 안내하되 최종 결정은 사용자에게 맡깁니다.
- 동의는 명시적이어야 합니다. 모델 다운로드, 폴더 인덱싱, 컴퓨터 사용(computer-use) 기억, 도구 승인은 기본값이 아니라 사용자의 결정입니다.

## 모드 정책 (Mode Policy)

- 기본 모드(Basic mode)와 고급 모드(Advanced mode)는 동일한 기능을 제공합니다.
- 기본 모드는 일상적인 평이한 언어를 사용합니다.
- 고급 모드는 더 깊은 실행 세부 정보를 보여줍니다.
- 관리자 모드(Admin mode)만이 추가적인 권한을 가집니다.

## 엔지니어링 정책 (Engineering Policy)

- 명시적 인터페이스와 의존성 주입을 우선합니다.
- 모델 카탈로그와 모델 워크플로 정책을 중앙 집중화합니다.
- 숨겨진 전역 상태와 암묵적 폴백(silent fallback)을 피합니다.
- 그래프 데이터와 마이그레이션 안전성을 보존합니다. 마이그레이션은 백업 우선(backup-first), 멱등성(idempotent), 재진입 가능(re-entrant)해야 하며 사용자 데이터 디렉터리는 절대 삭제하지 않습니다.
- 단순 구현 세부사항뿐만 아니라 제품 정책 동작을 검증하는 테스트를 추가합니다.
