# 왜 Lattice AI인가

현재 릴리스: **14.0.0 — Living Synthesis**.

**모델은 바꿔도, 내 지식은 남는 로컬 AI 브레인.**

AI 모델은 빠르게 바뀝니다. 오늘 쓰는 모델이 내일 교체될 수 있고, 클라우드 채팅 기록은 여러 도구에 흩어지기 쉽습니다. Lattice AI는 모델이 아니라 **당신의 Brain이 영속적인 자산**이 되도록 존재합니다.

## 문제점

대부분의 AI 제품은 모델에서 출발해 사용자의 컨텍스트를 일회성 프롬프트 재료로 취급합니다. 실제 업무에서는 이 방식이 쉽게 무너집니다.

- 프로젝트 결정 사항이 오래된 채팅 속에 묻혀 사라집니다.
- 문서와 노트가 대화와 단절된 채 따로 놉니다.
- 모델을 바꾸면 유용한 맥락까지 잃기 쉽습니다.
- 그래프 도구는 사용자 가치보다 구현 세부 사항을 먼저 드러냅니다.
- 클라우드 전용 제품은 내 지식을 직접 확인하거나 백업·이전하기 어렵게 만듭니다.

## Lattice의 해답

Lattice AI는 대화, 문서, 기억, 결정, 관계, 그리고 출처 프로비넌스를 개인 로컬 Brain에 보관합니다. 모델은 로컬에서 실행할 수도 있고, 원할 때만 OAuth CLI나 API 키로 클라우드 워커를 고용할 수도 있습니다. 기본값은 로컬이며, 어떤 모델을 쓰든 Brain은 그대로 남습니다.

그래프는 눈에 보이는 근거로서 중요하지만, 그래프 편집기 자체가 제품의 정체성은 아닙니다. 제품의 정체성은 로컬 우선 디지털 브레인입니다. 사용자가 대화하거나 출처를 추가하면 그것이 기억으로 들어가고, 실제 관계가 드러나며, 그 기억을 바탕으로 검토된 자동화를 실행할 수 있습니다.

현재 메인 브랜치의 경험은 의도적으로 대시보드가 아닙니다. 첫 화면은 대화 컴포저를 중심으로 살아 있는 지식 여정을 안내합니다. 채팅, 파일, 폴더, 노트, 웹 입력이 Brain으로 흘러들고, 범위가 정돈된 실제 그래프가 새로운 연결을 보여주며, 근거 기반 다음 행동은 어떤 기억과 증거를 사용하는지 설명합니다. 근거가 뒷받침된 Brain Brief, 더 깊은 기억 계층, 런타임 세부 정보는 첫 화면을 운영자 콘솔로 만들지 않으면서도 언제든 열 수 있습니다. 기본 탐색은 사람의 작업 흐름인 채팅·출처·기억·작업(Chat, Sources, Memory, Work)을 따르며, 모델·워크스페이스 제어·관리자 기능은 보조 영역에 머뭅니다.

## 실용적인 사용 이유

- 팀이 무엇을 결정했는지 묻고 실제 출처를 바로 확인합니다.
- 문서를 추가해 검색 가능한 개인 기억을 쌓습니다.
- 오래된 노트, 프로젝트 결정 사항, 파일을 바탕으로 새 작업을 준비합니다.
- 모델을 옮겨도 컨텍스트를 유지합니다. 클라우드는 선택 사항이며 기본은 로컬입니다.
- Brain을 암호화된 `.latticebrain` 아카이브로 내보내거나 복원할 수 있습니다.
- 기반 Brain을 바꾸지 않고 한국어와 영어를 함께 사용할 수 있습니다. 한국어 질의는 단순히 접두사가 겹치는 문자열이 아니라 조사까지 포함해 한국어로 이해됩니다.
- 모델이나 근거가 없을 때 그럴듯한 가짜 답변을 지어내지 않습니다.
- 내 기기가 실제로 실행할 수 있는 모델에서 동작합니다. 에이전트 루프는 모델이 무엇을 생성할 수 있는지 실측하고 이에 맞게 적응합니다. 도구 호출을 직접 출력하기엔 너무 작은 모델도 실패로 끝내지 않고 번호 선택지로 안내하며, 모든 경로에서 동일한 권한 게이트와 안전장치를 유지합니다.

## Lattice AI가 아닌 것

- 기본값이 호스티드 SaaS인 서비스가 아닙니다.
- 단순한 모델 런처가 아닙니다.
- 단순한 그래프 뷰어가 아닙니다.
- 범용 대시보드가 아닙니다.
- 노트 앱 복제품이 아닙니다.
- ChatGPT나 Claude 복제품이 아닙니다.

Lattice AI는 모델이 바뀌어도 자신의 지식이 살아남기를 원하는 사람들을 위한 도구입니다.
