# 프라이버시

> **상태: 정본 — 현재 릴리스: 14.1.1 — Living Synthesis**

Lattice AI는 기본적으로 로컬 우선입니다. 프롬프트, 파일, 지식 그래프, 브레인 아카이브를 기본값으로 Lattice 소유 서버에 전송하지 않습니다. 사용자가 명시적으로 선택한 일부 기능만 외부 서비스와 통신하며, 그 경로를 아래에 투명하게 명시합니다.

## 로컬에 저장되는 데이터

별도의 `LATTICEAI_DATA_DIR`을 지정하지 않으면 기본 로컬 브레인 데이터는 `~/.ltcai` 아래에 저장됩니다. 사용자 소유의 미러 또는 레거시 볼트 데이터는 `~/.ltcai-brain`이나 사용자가 지정한 경로에 저장될 수 있습니다.

로컬에 저장되는 데이터는 다음과 같습니다:

- 로컬 프로필 및 세션 메타데이터
- 대화, 기억, 의사결정, 워크플로우 실행 기록
- 지식 그래프 노드, 엣지, 출처 이력(프로비넌스), 검색 인덱스
- 업로드된 문서 원본 블롭 및 추출 텍스트
- 감사 로그 및 관리자 작업 이벤트
- 백업 및 암호화된 `.latticebrain` 아카이브
- 모델 및 런타임 상태 메타데이터

## 기기 밖으로 나갈 수 있는 경로

토큰이 존재한다는 이유만으로 데이터가 기기 밖으로 전송되지는 않습니다. 모든 외부 통신은 명시적 설정과 사용자·관리자의 실행이 필요합니다.

외부 통신 경로는 다음과 같습니다:

- **클라우드 모델**: 클라우드 경로가 설정되어 있고 에스컬레이션 정책(또는 명시적 `/cloud` 접두사)이 이를 사용하는 경우에만 프롬프트와 컨텍스트가 선택한 제공업체로 전송됩니다. 기본값은 로컬입니다. 민감·비공개 노드와 비밀 파일이 필터링되고 외부 전송 전 PII·비밀 문자열이 마스킹(`lattice-core::redact`)되며, 모든 클라우드 턴은 원문 내용 없이 형태 정보(제공업체·모델·사유)만 외부 전송 감사 로그에 기록합니다. 클라우드 응답에서 추출된 지식은 검토 센터의 `kg_cloud_expansion` 제안으로 스테이징되며, 사람이 승인하기 전에는 그래프에 기록되지 않습니다(`auto_commit` 기본값 꺼짐). 자격 증명 모드는 `api_key`(OpenAI 호환, 과금 없는 `GET /models` 프로브)와 `cli_oauth`(로컬 OAuth 인증된 `agy` / `grok`) 두 가지를 지원합니다.
- **모델 다운로드**: 사용자 동의 후 모델 식별자와 다운로드 요청이 Hugging Face 또는 Ollama 레지스트리 등으로 전송됩니다.
- **Telegram**: v11.6.0에서 제거되었습니다. 더 이상 Telegram으로 메시지가 외부 전송되지 않으며 `LATTICEAI_TELEGRAM_*` 환경 변수도 읽지 않습니다.
- **Brain Network**: 피어 간 동기화는 명시적 페어링과 네트워크 작업 실행이 필요합니다.
- **PostgreSQL / Docker**: 확장 모드 설정은 사용자가 opt-in한 로컬 또는 네트워크 서비스에만 연결합니다.
- **업데이트 확인**: 명시적으로 활성화하지 않으면 비활성화되어 있습니다.
- **마켓플레이스 / 레지스트리 새로고침**: 사용자 또는 관리자가 직접 호출할 때만 원격 레지스트리에 접속합니다.
- **설치 도우미 패키지 설치 (12.0.0+)**: `/setup/install`은 요청에 명시되고 서버가 산출한 허용 목록에 포함된 항목에 한해 `brew`, `pip`, `uv`를 실행할 수 있습니다. 실행 명령은 요청이 아니라 서버 계획에서 생성되며, 기본 경로는 수동 설치입니다. 페이지를 열었다고 자동으로 설치되지 않습니다.

## `.latticebrain` 아카이브

`.latticebrain` 아카이브는 이식 가능한 암호화 브레인 번들입니다. 그래프 데이터, 대화, 프로비넌스, 블롭 또는 블롭 참조, 메타데이터, 무결성 해시를 포함할 수 있습니다. 암호 문구가 없어도 아카이브 버전, 생성 시각, 크기, 매니페스트 구조 같은 비내용 메타데이터는 확인할 수 있습니다. 잘못된 암호 문구, 위변조, 미지원 버전, 경로 이탈(path traversal)은 모두 fail-closed로 거부됩니다.

## 스크린샷 및 로그

릴리스 스크린샷은 로컬 모의·데모 데이터로 생성됩니다. 시크릿으로 보이는 값은 로그, 감사 이벤트, 보안 내보내기, 프론트엔드 미리보기, 훅 패킷에 기록되기 전에 중앙에서 마스킹됩니다. 권한 알림에는 승인 토큰 원문이 아니라 짧은 힌트와 선택적 `LATTICEAI_PERMISSION_UI_URL` 검토 링크만 포함됩니다.

## 사용자 통제권

사용자는 자신의 브레인을 언제든 백업, 내보내기, 검사, 검증, 이전할 수 있습니다. 패키지 배포와 공개 서버 운영은 소유자가 직접 수행하며, 로컬 사용이 기본값입니다.

삭제 역시 사용자의 통제 아래 있으며 자동으로 일어나지 않습니다. 색인된 폴더에서 사라진 파일은 자동 삭제되지 않고 *보고*만 되며, 폴더 정리(prune) 흐름에서 제거 대상을 먼저 보여준 뒤 명시적 확인을 받아야 그래프에서만 정리됩니다. 어떤 정리 경로도 디스크의 원본 파일을 삭제하지 않습니다. v12.0.0부터 복원(restore)은 실행 중인 프로세스에 즉시 반영되어 재시작 없이 바로 복원된 브레인으로 응답합니다.
