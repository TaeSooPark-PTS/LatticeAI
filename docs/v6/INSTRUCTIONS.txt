1. Product Principles (Non-Negotiable)
────────────────────────────────────

Lattice AI is a local-first Digital Brain.

Do NOT turn it into:
- ChatGPT clone
- Claude clone
- Cursor clone
- VS Code clone
- Notion clone
- Obsidian clone
- plain model launcher
- plain graph database UI

Preserve:
- Models are temporary. Knowledge is durable.
- The Brain is the durable asset.
- Local-first by default.
- Explicit consent for external communication.
- User ownership of memory, graph, archives, backups, and restore.
- Separation of Brain use and Admin use.
- Powerful features without overwhelming normal users.

3. Major Work Lanes
────────────────────────────────────

Lane A — Review Center Completion (MANDATORY)

This lane is required and must be completed.

Review Center must become feature-complete and production-ready.

Required:

1. Snoozed Filter
- Add Snoozed filter to Review Center.
- Minimum filters:
  - Pending
  - Snoozed
  - All
- Optional:
  - Approved
  - Dismissed

2. Unsnooze Support
Backend:
- Add explicit unsnooze policy transition.
- Only valid from stored status "snoozed".
- Must set:
  - status = pending
  - snoozed_until = null
- Invalid transitions must return HTTP 409.

API:
- Expose unsnooze endpoint.

Preferred endpoint:

POST /automation/reviews/{item_id}/unsnooze

Frontend:
- Add Unsnooze action.
- Display snoozed_until clearly.
- Make Snoozed state understandable.

3. Preserve Existing Semantics
- run_now remains preview/regenerate.
- run_now does NOT approve.
- Snooze expiry remains read-time only.
- No mutation on read.
- Approve/dismiss behavior remains unchanged.

4. Tests
Required:
- unsnooze success
- unsnooze invalid transition
- workspace isolation
- effective_status behavior
- API coverage
- OpenAPI coverage

5. Review Center UX
Pending:
- Approve
- Dismiss
- Snooze
- Run now

Snoozed:
- Unsnooze
- Dismiss
- Run now

Approved/Dismissed:
- Read-only if shown

Review Center must feel understandable and reversible.
