# Lattice AI v7.8.0

## Brain Chat Home UX Simplification

7.8.0 makes the product easier to understand at a glance. The default Brain
surface now leads with chat, starter prompts, and the composer instead of
placing command-center, ingestion, timeline, proof, overview, and care panels
above the conversation.

### Highlights

- Brain Chat Home is chat-first and composer-first.
- Source ingestion, readiness, proof, timeline, model continuity, overview, and
  care controls are available through one utility drawer.
- Workspace navigation is visible on the default Brain surface.
- Deep memory controls stay hidden until the user intentionally travels deeper.
- Obsolete Brain UX components were removed.
- Product and architecture readiness gates now target 7.8.0.
- Release screenshots, the walkthrough GIF, and capture notes were refreshed
  under `output/release/v7.8.0/`.
