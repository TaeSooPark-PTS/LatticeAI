# Skill: weekly_review

description: 이번 주 Brain에 들어온 것과 남은 할 일로 주간 회고 문서를 만든다.

## 메타데이터
- **버전**: 1.0.0
- **카테고리**: knowledge
- **위험도**: low
- **필요 권한**: workspace_write

## 설명

지난 한 주 동안 Brain에 실제로 들어온 자료(문서·메모·대화)와 아직 열려 있는
항목을 근거로 주간 회고 문서를 만든다. 사람이 기억을 짜내는 대신, **Brain이
가진 기록에서만** 한 주를 재구성한다.

설치하자마자 값이 보이는 이유: 이미 쌓인 것만 쓰기 때문에 추가 입력이 필요 없고,
결과가 그대로 다음 주 계획의 출발점이 된다.

## 거버넌스

`risk.json` 참고. 요약: `risk=write`, `destructive=false`, `shell=false`,
`network=false`, `auto_approve=true`, `sandbox=workspace`, `rollback=snapshot`.

## 트리거 조건

호출해야 하는 상황:
- "이번 주 정리해줘", "주간 회고 써줘"
- 금요일/월요일 루틴으로 한 주를 닫고 열 때
- 프로젝트 세션의 남은 할 일을 한 장으로 보고 싶을 때

호출하면 **안** 되는 상황:
- 특정 문서 하나의 요약 → `summarize_document`
- 회의 하나의 결정/할 일 정리 → `meeting_notes`

## 근거 규칙 (중요)

- 이 주에 **Brain에 기록이 있는 것만** 쓴다. 기록이 없는 성과를 지어내지 않는다.
- 각 항목 뒤에 출처(문서 제목/파일명)를 남긴다.
- 한 주 동안 들어온 것이 없으면 "이번 주 새로 들어온 자료가 없습니다"라고 쓰고
  끝낸다. 빈 주를 채우지 않는다.

## Side Effects

| 항목 | 내용 |
|------|------|
| 파일 변경 | 대상 경로에 마크다운 1개 생성 (기존 파일이면 변경 제안) |
| 생성 파일 | `reviews/<week>.md` (기본) |
| 프로세스 | 없음 |
| 네트워크 | 없음 |

## Rollback

`rollback=snapshot`. 실패 시 쓰기 전 상태로 복구된다.

`schema.json` 참고.

## 실행 조건

- LLM 모델이 로드되어 있어야 함
- Brain에 최소 1건의 자료가 있어야 의미 있는 결과가 나온다 (없으면 위 규칙대로
  "없음"을 그대로 기록한다)
