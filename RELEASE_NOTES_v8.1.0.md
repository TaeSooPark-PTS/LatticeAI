# Lattice AI v8.1.0 Release Notes

Intuitive Brain Home release.

## Highlights

- Brain Home now starts with the living Brain directly above the composer, so the
  user immediately sees where to talk and what the Brain is doing.
- Replaced dashboard-style growth metrics with a narrative first screen: Brain
  status, just-remembered context, connected topic, and next-best action.
- Primary actions are explicit: talk to Brain, add sources, or open the memory
  graph.
- Mobile and 320px layouts keep the Brain and composer in the first viewport.
- Refreshed 8.1.0 screenshots, walkthrough GIF/WebM, package metadata, Tauri
  metadata, static app assets, readiness gates, and current-release docs.
- Preserved the 8.0 runtime architecture contract while making the default Brain
  experience more product-like and easier to understand.
