# Lattice AI v4.5.0 Graph Experience Report

## Goal

The graph should feel like a Digital Brain, not a graph dump.

## Reset Applied

- `Graph` tab is presented as `Map`
- `Provenance` is presented as `Sources`
- the hero metric is `Source coverage`
- empty state asks users to capture files/folders to create connected ideas
- graph exploration copy emphasizes ideas, connections, focus, and source-backed memory
- large graph controls keep search, importance, labels, fit, and group collapse in place

## Basic Mode

Basic mode shows:

- source-backed memory language
- humanized graph entities
- focus mode for selected ideas
- important ideas list

It does not expose:

- graph endpoint names
- Cytoscape implementation detail
- raw graph records
