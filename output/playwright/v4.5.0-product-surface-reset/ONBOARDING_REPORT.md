# Lattice AI v4.5.0 Onboarding Report

## Intended Journey

1. Login
2. Workspace Selection
3. Environment Analysis
4. Model Recommendation
5. Model Installation
6. Model Validation
7. Mode Selection
8. Brain Usage

## Reset Applied

The first-run guide now behaves as a setup companion:

- shows progress across all 8 journey steps
- exposes one primary next action
- keeps Model Setup and Brain Map as direct secondary actions
- marks completed steps as ready and incomplete steps as next/later
- avoids asking users to understand backend state before they can continue

## Restored Experiences

- Login remains available from Account.
- Workspace creation/selection remains available from Workspaces.
- Model setup is directly reachable from the first-run guide.
- Mode selection remains global and in Preferences.
- Brain usage is one click away through Brain Map.
